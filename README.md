## `01` · Sobre mim

Olá! Sou **Wermesson Silva**, estudante de Tecnologia da Informação e desenvolvedor com foco em **Backend**.

Tenho interesse na construção de aplicações web, utilizando Java e seu ecossistema para desenvolver soluções organizadas e funcionais.

Neste perfil, compartilho projetos pessoais e acadêmicos, exploro tecnologias e registro parte da minha evolução como desenvolvedor.

- **Foco atual:** desenvolvimento backend com Java.
- **Ecossistema:** Spring Boot, JSF e PostgreSQL.
- **Desenvolvimento web:** Angular, JavaScript, HTML e CSS.
